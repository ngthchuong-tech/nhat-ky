Kết nối Google Sheet

App này lưu toàn bộ dữ liệu trên Google Sheet của bạn thông qua một Apps Script Web App. Cần dán đường link Web App vào đây trước khi dùng.

Chưa có link? Làm theo các bước:

  1. Tạo 1 Google Sheet trống.
  2. Tiện ích mở rộng → Apps Script.
  3. Dán nội dung file Code.gs đi kèm vào, bấm Lưu.
  4. Triển khai → Lượt triển khai mới → Ứng dụng web → Quyền truy cập: Anyone.
  5. Copy link "Web app URL" và dán vào ô trên.
